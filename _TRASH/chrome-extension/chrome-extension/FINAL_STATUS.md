## 📋 **Final Steps (5 minutes)**

### 1. Create Icons
```bash
cd chrome-extension
python create_icons.py
```
Or manually:
- Copy `frontend/public/logo.png` to `chrome-extension/icons/`
- Resize to: 16x16, 48x48, 128x128
- Name: `icon16.png`, `icon48.png`, `icon128.png`

### 2. Load Extension
1. Chrome → `chrome://extensions/`
2. Enable Developer mode
3. Load unpacked → Select `chrome-extension` folder

### 3. Configure
1. Click extension icon
2. Settings → Set API URL: `http://localhost:5000`
3. Save

### 4. Test
1. Visit LinkedIn profile
2. Click "Analyze with ResumeScore"
3. Enter job description
4. Analyze!
