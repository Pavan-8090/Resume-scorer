ICON INSTRUCTIONS
=================

You need to create icon images for the Chrome extension.

Required sizes:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)  
- icon128.png (128x128 pixels)

You can:
1. Use the logo.png from frontend/public/logo.png
2. Resize it to these dimensions
3. Or create new icons with a resume/document theme

Quick way to create icons:
- Use online tools like: https://www.favicon-generator.org/
- Or use image editing software to resize your logo
- Or use the logo from your frontend: frontend/public/logo.png

For now, you can use any PNG images with these names and the extension will work.
